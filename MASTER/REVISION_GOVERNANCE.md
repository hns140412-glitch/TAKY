# REVISION GOVERNANCE — REV_00

PRE-CONFIRMATION STATE
→ ALL MASTER / GUIDE / DOMAIN / APP = REV_00

TEST / REVIEW / REMASTER / CANDIDATE CHANGES
→ SHALL NOT INCREMENT REVISION NUMBER

EXPLICIT USER FINALIZATION
→ ESTABLISHES THE FIRST OFFICIAL REVISION

POST-FINALIZATION UPDATE
→ REVISION NUMBER MAY INCREMENT ACCORDING TO APPROVED UPDATE SCOPE

HISTORICAL FILE REVISION LABEL
≠ CURRENT OFFICIAL REVISION

/검토 ≠ write
/반영 or 타키 반영 = approved integration workflow; does not itself increment revision.
