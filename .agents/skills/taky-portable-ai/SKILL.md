# TAKY Portable AI

Use only under the existing TAKY authority. First verify AGENTS.md, STATE.md, current HEAD/status and applicable current canonical source.

1. Inspect the local environment with: python -m TAKY2.portable_ai doctor.
2. Register one bounded task using submit --title, --owner CODEX or CLAUDE, --scope. Keep and reuse the returned task ID.
3. Attach real local artifacts via evidence TASK_ID --file PATH. Never attach credentials and never promote your own evidence to verified.
4. Use list/show or the read-only 127.0.0.1 serve dashboard to inspect the task.
5. To execute a provider, require existing TAKY2 approved plan/invocation and receipt-bound preflight. No ad hoc shell execution, no fallback to a paid API, no retries without a new authority path.
6. Maintain dirty worktree, honor no-push/no-merge/no-deploy and user Key/Cost gates.
7. Do not claim working IDE editor, browser agent, autonomous multi-agent, or native ChatGPT local event interception. These are separate integration tasks.
