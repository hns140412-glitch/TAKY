description: Process research through TAKY mining, indexing, learning, and promotion boundaries.
---
Search for genuinely new evidence, not duplicates of already indexed material.
Preserve provenance, date, source quality, applicability, and contradictions.
Flow: RAW -> INDEX -> LEARNING -> RELATION -> EXECUTION -> OUTCOME -> GROWTH.
Never write a discovery directly into CURRENT and never treat a stored lesson as learned behavior until it is bound to an executable rule/skill/hook/test/template/tool route and produces outcome evidence.
Use typed relations with provenance; exact CURRENT/authority matches outrank semantic similarity.
Confirmed repeated failures route through root-cause -> alternate route -> recovery outcome -> regression candidate.
CURRENT_BEST requires the Growth Lineage Contract gates and human review; no automatic promotion.
Prefer existing index/learning evidence before new mining.
Record conflicts and uncertainty instead of flattening them. Handoff is transport/recovery, not semantic authority.
