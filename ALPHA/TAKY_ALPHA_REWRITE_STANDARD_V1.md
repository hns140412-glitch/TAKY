# TAKY ALPHA REWRITE STANDARD V1
Date: 2026-10-04
Status: AUTHORING STANDARD / NO RELEASE AUTHORIZATION

## 1. Purpose
Alpha is NOT a promotion of Beta documents, a routing graph, a coverage matrix, or a pointer bundle.
Alpha is a newly authored whole-system operating specification synthesized from Frozen Beta plus validated later evidence.

## 2. Mandatory input
1. Frozen Beta exact snapshot and all preserved OPEN/HOLD/conflict evidence.
2. Relevant account-wide conversation decisions, corrections, reversals and failure causes.
3. Current canonical owners and GitHub main.
4. Validated post-freeze candidate evidence, explicitly separated from authority.
5. Drive/Library CURRENT and source evidence.
6. Lower product/application evidence: Ready & Set, Hide & Seek, Snap & Pop, TAKY-MOBILE.
7. Engines: Learning Engine, Planner, Explorer Crew, Badge/Reward, SAVEY.
8. Work OS / ArchiGrow and LearningGrow.
9. Design/UI/asset execution and validation evidence.
10. Shared auth/sync/offline/private-family/runtime evidence.

## 3. Required writing model
Each Alpha chapter must state:
- WHY / user intent
- OWNER / authority
- INPUT
- DECISION / policy
- EXECUTION FLOW
- DATA / state
- APP/ENGINE consumers and producers
- UI/runtime manifestation where applicable
- EVIDENCE / validation
- FAILURE MODES learned from Beta
- DEFENSIVE RESPONSE
- OPEN/HOLD boundaries
- HANDOFF to next subsystem

A pointer or filename alone NEVER satisfies a chapter.

## 6. Rewrite rules
- Preserve valid Beta decisions; do not copy Beta structure blindly.
- Resolve duplicates and stale rules by meaning and authority.
- Record important failure-path lessons as enforceable Alpha behavior.
- Later validated corrections may evolve Beta, but may not silently erase lineage.
- Lower apps/engines/pipelines must be described as actual end-to-end operating flows, not names or pointers.
- Structural completion does not fabricate runtime/device/deployment proof.
- Explicit owner gaps remain OPEN until actually resolved.

## 8. Exit
Alpha is complete only when a reader can execute and reason about TAKY from the Alpha itself without reconstructing the system from dozens of pointer files.
