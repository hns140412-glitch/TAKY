## 5 HARD GATES
KEY / CONTEXT / ROUTE / COST / DONE are guidance boundaries, not goals in themselves.

- KEY: return to USER intent and authority.
- CONTEXT: narrow to verified snapshot/delta.
- ROUTE: stop same-failure repetition and choose a materially different valid path.
- COST: avoid unnecessary calls and choose the cheapest sufficient route.
- DONE: reject false completion and return to missing evidence/verification/rework.

A gate may deny the current unsafe/invalid action while still returning a REDIRECT path.
Terminal blocking is reserved for explicit USER stop or true safety/integrity hard-stop conditions.
