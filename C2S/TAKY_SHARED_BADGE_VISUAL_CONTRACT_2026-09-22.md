# TAKY SHARED BADGE VISUAL CONTRACT — 2026-09-22

Status: RECOVERED VISUAL DIRECTION / CROSS-APP CONTRACT
No new mockup generated by this document.

## 1. Existing visual lock

Preserve recovered direction:
- circular badge;
- hand-drawn feeling;
- pastel palette;
- visually stronger center with softer/faded outer edge;
- child Profile Character as protagonist;
- witty/situation-based scene rather than generic trophy icon;
- Green → Blue → Red → Gold → Platinum;
- 1–5 BADGE_GROWTH_MARKs arranged around the upper semicircle.

## 2. Composition

COMMON_BADGE_ART
+ CHILD_IDENTITY_LAYER
+ THEME_EXPRESSION_LAYER
+ BADGE_GROWTH_LAYER

Do not regenerate a disconnected child identity for every badge.

Identity-defining traits remain stable.
Theme may change:
- clothing;
- pose;
- props;
- background;
- light;
- scene/effects.

Theme may not change:
- profile identity;
- tier/star state;
- award state;
- EXP/gem economy;
- power/ability.

## 3. Character relationship

Profile Character is the badge protagonist.
Exploration Crew may appear as a supporting scene element only when the badge meaning requires it.

Crew presence must not imply:
- crew-owned badge;
- crew power;
- crew rarity;
- reward multiplier.

## 4. Badge growth marks vs Snap currency

BADGE_GROWTH_MARK:
- progression ornament;
- non-spendable;
- upper-semicircle position;
- pastel jewel/star character;
- no balance count;
- no shop affordance.

SNAP_WISH_GEM:
- Snap-owned currency;
- spendable;
- inventory/balance semantics;
- wish-shop affordance;
- ledger-backed.

They must use visibly distinct silhouettes/assets and motion.

## 5. Tier semantics

Green / Blue / Red / Gold / Platinum represent badge-history/progression presentation only.

They do not mean:
- intelligence;
- mastery;
- child rank;
- character level;
- rarity;
- social status.

## 6. Surface behavior

Allowed:
- small contextual acknowledgement when a canonical badge is awarded/progresses;
- collection/detail view;
- profile-derived display;
- growth-area preview.

Forbidden:
- every app inventing its own badge style;
- app-specific recoloring that changes tier meaning;
- full-screen reward explosion;
- leaderboard/rank presentation;
- badge farming CTA;
- badge stars visually merging with Snap gem balance.

## 7. State set for future UI

BADGE_LOCKED_BY_CANONICAL_REVIEW — internal only, not child-facing
BADGE_UNSEEN
BADGE_SEEN
BADGE_PROGRESS
BADGE_NEWLY_AWARDED
BADGE_DETAIL
BADGE_THEME_ASSET_PENDING — internal/fallback treatment
BADGE_MIGRATED_HISTORY — if legacy migration approved later

WORKING_DRAFT badges must never render as earnable child-facing items.

## 8. Art asset authority

Current runtime compositor proves structure, not final reviewed art.
Canonical reviewed asset set remains OPEN.

Existing historical/reference images must be treated as lineage/reference unless explicitly approved as golden assets.
