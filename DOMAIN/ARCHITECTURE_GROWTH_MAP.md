Status: REV_00 / ACTIVE DOMAIN GROWTH MAP

Purpose: Keep the architecture system from being mistaken for complete when only the conceptual skeleton exists. Drive the next work toward the highest-value missing flesh.

## 0. North Star

Target operating context: approximately **20-40 person architectural design office**.

The system must improve both:
1. **PURSUIT / FRONT-END** — win work faster with grounded, buildable, persuasive design alternatives;
2. **PRODUCTION / POST-AWARD** — deliver the won work with less rework, stronger technical consistency and growing company intelligence.

These are one continuous data loop, not competing products.

`PURSUIT MODEL -> PROJECT DELIVERY -> FIELD/REVIEW OUTCOME -> COMPANY LEARNING -> NEXT PURSUIT`

## 1. Locked direction

- TAKY is not primarily a validator.
- Validation is a truth/regression safety rail.
- Core behavior is goal-driven exploration, multiple-method search, comparison, learning and evolution.
- `Reality Locked / Possibility Open`.
- Regulatory review should seek lawful implementation paths, not merely explain failure.
- Company standards are `CURRENT_BEST`, not eternal truth.
- Company cases are evidence, not automatic standards.
- `FRONTIER` keeps evidence-backed experiments alive.
- Conversation is a core system-building source and must compile without silent loss/false convergence.
