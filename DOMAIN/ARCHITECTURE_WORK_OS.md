## 2. CAD ↔ EXCEL
For geometry/area verification, prefer recoverable CAD object evidence where available:
- layer
- object type
- closed polyline / boundary
- text
- color
- location
- calculated area / geometry

Screenshots and PDFs may support visual review but SHALL NOT be the sole final numeric/geometry authority when underlying CAD object evidence is available and materially required.

Excel review should distinguish:
- entered value
- formula
- subtotal / total
- source evidence
- cross-sheet consistency
- uncertainty / check state

`REFERENCE DATA ≠ PROJECT FACT`
A reference project value SHALL NOT be promoted to the target project without target-project evidence.
