# TAKY BADGE 60 PRODUCTION SPEC V3.0 — SCENE-FIRST / DEDUP

**상태:** 제작명세 전면 재작성 / 생성 프롬프트 미작성 / 이미지 생성 HOLD

## 0. Authority
- **LOCKED:** 배지 ID, 현재 배지명, 핵심 상세설명, Story Authority.
- **STYLE AUTHORITY:** 현재 대화에서 사용자가 제시한 10장 배지 예시. 이 예시의 표현 방식이 공통 화풍/장면 문법의 기준이다.
- **DEPRECATED:** V2.1의 `Motif Authority`, 기존 `Prompt Contract`, 공통 BASE/리본/핀/컴퍼스 바 같은 아이콘형 프레임 강제.
- 기존 모티프는 의미 보존의 참고일 뿐, 장면 전달력이나 60종 중복검사에 실패하면 유지하지 않는다.

## 1. 공식 표현 스타일 — `TAKY STORY VIGNETTE STYLE`
1. **원형 안의 한 장면:** 배지는 사물 아이콘 조합이 아니라, 한 번의 행동·사건·상황이 읽히는 작은 동화 장면이다.
2. **초고밀도 파스텔/과슈 손그림:** 부드러운 붓결, 종이·천·나무·금속·물 같은 재질감, 따뜻한 자연광, 얕은 대기 원근을 사용한다.
3. **장면 중심, 상징 보조:** 핵심 의미는 실제 행동/상황으로 먼저 전달하고, 상징은 보조로만 쓴다.
4. **원형 크롭:** 정사각형 고해상도 마스터에서 원형 장면을 구성하고 원형 바깥은 투명. 공통 금속 테두리·메달 rim·리본·별·UI 프레임은 만들지 않는다.
5. **인물 표현:** 필요하면 얼굴 없는 손·발·부분 신체를 사용할 수 있다. 고정 탐험대 캐릭터를 임의 삽입하지 않는다.
6. **위트:** 얼굴 표정이나 글자로 설명하지 않고, 상황의 반전·행동·배치로 읽힌다.
7. **배경:** 의미를 이해시키는 데 필요한 환경은 허용한다. '배경 거의 없음'을 강제하지 않는다. 다만 풍경 자체가 주제가 되어 의미를 덮으면 실패.
8. **텍스트:** 배지 원화 안에 이름, 숫자, 설명문, 버튼, 등급, 별점, 로고를 넣지 않는다. 단, 장면 자체에 숫자가 필수인 경우에도 우선 비문자적 표현으로 해결한다.

## 2. Scene Grammar
- `PRIMARY ACTION` : 지금 일어나는 행동 1개.
- `PRIMARY ANCHOR` : 64px에서도 먼저 읽히는 고유 물체/관계 1개.
- `SUPPORT` : 의미를 이해시키는 보조 요소 1~3개.
- `SETTING` : 사건을 이해시키는 최소 환경.
- `ATMOSPHERE/FX` : 빛·움직임·공기감. 의미를 대신하지 않는다.
- 한 장면 안에 '전/후'를 억지로 두 컷처럼 나누지 않는다. 가능한 한 **하나의 순간**에 전환이 읽히게 만든다.

## 3. 60종 중복 방지 규칙
- 각 배지는 다음 6개로 `VISUAL FINGERPRINT`를 만든다: `주요 앵커 / 행동동사 / 카메라 거리 / 공간 / 방향성 / 보조 소품`.
- **주요 앵커+행동 조합은 60종에서 1회만 사용한다.**
- 같은 `지도·나침반·신발·발자국·깃발·부메랑·일출·화살표`를 '탐험 느낌'이라는 이유로 반복하지 않는다.
- 같은 물체가 맥락상 필요해도 **주요 앵커로 재사용하지 않는다.** 반복 소품은 후경/보조에만 허용.
- 서로 가까운 의미의 배지는 카메라/공간/주요 동작을 의도적으로 다르게 설계한다.
- 생성 직전 60종 전체 썸네일을 놓고 `실루엣 / 주요 물체 / 행동 / 배경 / 색온도` 5축 중 **최소 3축 이상 차별**되지 않으면 FAIL.
- 단순히 '다른 색'만 입힌 것은 차별로 인정하지 않는다.

## 4. 공통 출력
- 정사각형 고해상도 마스터.
- 원형 내부 일러스트, 원형 바깥 투명.
- 최종 분리: `BG / SUBJECT / FX / COMPOSITE`. 공통 장식 BASE는 사용하지 않는다.
- 64 / 120 / 200 / 320px 축소 검수.
- 획득/잠금/별/티어/프로필 상태는 원화에 bake-in 금지.

## 5. Gate
- G0 — 이름·핵심 상세설명·Story Authority 보존
- G1 — 이름을 가려도 핵심 행동/사건이 장면으로 읽힘
- G2 — 표시명과 장면의 의미 연결이 억지 은유 없이 설명 가능
- G3 — 64px에서 고유 PRIMARY ANCHOR가 먼저 읽힘
- G4 — 공식 10장 레퍼런스의 장면형 파스텔 동화 미감과 일치
- G5 — 60종 VISUAL FINGERPRINT 중복검사 PASS
- G6 — 장면 이해에 불필요한 상징·풍경·FX 제거
- G7 — 공통 rim/메달/리본/등급/UI/텍스트 없음
- G8 — BG/SUBJECT/FX 분리 가능
- G9 — 생성 프롬프트가 명세를 축약·왜곡하지 않음
- G10 — G0~G9 PASS 전 이미지 생성 금지
