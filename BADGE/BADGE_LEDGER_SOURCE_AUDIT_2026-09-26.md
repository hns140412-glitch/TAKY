## Implemented seam (NOT a live connection)
`BADGE/badge-ledger-projection-bridge.js` is a fail-closed, pure consumer that requires a trusted runtime-injected source with:
- `contract: TAKY_TRUSTED_BADGE_AWARD_HISTORY_SOURCE_V1`
- `loadCompleteHistory({child_id,badge_id})`, returning a complete scoped snapshot, checkpoint and row count
- `verifyAwardRow(row,{child_id,badge_id,checkpoint})`, verifying each actual ledger row and normalizing its receipt

It rejects absent connectors, partial history, mismatched member/badge, failed verification, duplicated IDs, out-of-order sequences and any row incompatible with the existing initial-award/reaward projection. Empty verified history = LOCKED; a verified first acquisition = EARNED/0 stars; five further verified reawards = tier promotion per current provisional within-tier rollover.

### Critical trust boundary
A JavaScript object saying `authority:'AWARD_LEDGER'` is NOT proof. The real Award Ledger owner must provide the read and row verification methods via trusted runtime composition, enforce authorization/member scope server-side or via its existing trusted storage, and expose authoritative receipt IDs/order. The local mock in tests is only a contract test, not live production evidence. Do not point this adapter at a badge event counter, candidate list, telemetry log, a user-supplied object, or a historical working catalog.
